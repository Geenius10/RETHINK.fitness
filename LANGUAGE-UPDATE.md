# Language / typography / icon update
- English UI translation expanded across static and dynamically rendered interface text.
- Exercise names and plan names remain unchanged.
- Placeholders, aria labels, titles, dialogs and dynamically inserted UI are translated.
- Fitness terminology uses standard English UI terms such as workout plan, exercise, set, reps, rest and performance.
- Extra Large text mode removed.
- Existing Extra Large preference migrates to Large.
- Large is a uniform +10% scale applied globally to text-bearing UI elements.
- R. + dumbbell icon integrated for 180, 192 and 512 px plus Apple touch icon.
- Service-worker and icon cache versions bumped.
