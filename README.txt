Geeniusapp – Version 1

Neustart des Projektnamens und der Versionierung.

Änderungen:
- App heißt jetzt Geeniusapp.
- Standard-Pause für neue Kraftübungen: 2:00 Minuten.
- Beim Öffnen einer einzelnen Übung gibt es nur noch Zurück, kein X.
- Satzmethoden: Normal, Supersatz, Dropsatz, Rest-Pause, Cluster-Satz, Pyramide, Pre-Exhaust, Giant Set, Back-off Set.
- Satzmethoden werden im Plan und im laufenden Training sichtbar markiert.
- Supersatz/Giant Set können mit einer bereits vorhandenen Übung verknüpft werden.
- Muskelgruppen-Checkboxen deutlich kleiner und ohne graue Pillen-/Schattenflächen.


Geeniusapp v1.1
- Wasserhaushalt sichtbar in Körper & Ernährung integriert.
- Flüssigkeitsziel Bestandteil der Ernährungsziele.
- Eigene Getränke mit Name, letzter Größe, Hydrierung, optional Kalorien/Koffein.
- Verlaufseinträge einzeln löschbar.
- Zuletzt verwendete Pläne anklickbar, solange der Plan existiert.
- Übungskonfiguration kompakter.
- Satzmethoden zeigen eine kurze methodenspezifische Erklärung.


Geeniusapp v1.2
- Satzmethoden besitzen eigene Parameter und Workout-Strukturen.
- Supersatz, Pre-Exhaust und Giant Set werden als zusammenhängende Kartenblöcke dargestellt.
- Gruppenpause beginnt erst nach der letzten Übung einer Runde.
- Dropsatz: Drops + prozentuale Lastreduktion.
- Rest-Pause: Anzahl Mini-Blöcke + interne Pause.
- Cluster: Clusterzahl, Wiederholungen pro Cluster + interne Pause.
- Pyramide: echte Wiederholungsfolge, Satzanzahl wird aus der Folge erzeugt.
- Back-off: Top-Set + definierte Anzahl leichterer Back-off-Sätze.
